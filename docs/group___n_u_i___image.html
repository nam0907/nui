Detailed Description

Image rendering module.

This module provides image abstraction and rendering functions for the NUI graphics library.

Images can be stored in memory, loaded from external storage, or provided by custom image backends through the image interface.

Generic image object.

This structure defines the image interface used by NUI.

Different image sources such as memory images, SD card images, or custom image providers can implement this interface.

Defines the pixel format used by an image object.

RGB565 image format.
