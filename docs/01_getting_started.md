# Getting Started

This guide explains the basic workflow required to start using the **NUI Graphics Library** in your project.

By the end of this guide, you will be able to:

* Add the NUI library to your project.
* Configure the required modules.
* Generate fonts and images using **NUI Tool**.
* Register a display driver.
* Draw your first text and image.

For more detailed information, refer to the corresponding guides in the documentation.

---

# Workflow

The typical development workflow when using NUI is shown below.

```text
Add NUI Library
        │
        ▼
Configure NUI
        │
        ▼
Generate Resources
(Font / Image)
using NUI Tool
        │
        ▼
Implement Display Driver
        │
        ▼
Register Driver
        │
        ▼
Draw Graphics
```

---

# Step 1 – Add the Library

Copy the NUI library into your project.

A typical project structure is shown below.

```text
Project
│
├── Application
├── Drivers
├── NUI
│   ├── core
│   ├── font
│   ├── image
│   ├── geometry
│   ├── widget
│   └── ...
└── main.c
```

Next, configure your compiler include paths.

The installation procedure depends on the development environment.

Supported environments include:

* Keil MDK
* STM32CubeIDE
* PlatformIO
* ESP-IDF
* GCC / Makefile
* CMake

See the **Installation Guide** for platform-specific instructions.

---

# Step 2 – Configure the Library

Open:

```text
nui_conf.h
```

Enable only the modules required by your application.

Example:

```c
#define NUI_USE_FONT          1
#define NUI_USE_IMAGE         1
#define NUI_USE_GEOMETRY      1
#define NUI_USE_WIDGET        0
```

Disabling unused modules helps reduce Flash and RAM usage.

More configuration options are described in the **Configuration Guide**.

---

# Step 3 – Generate Fonts and Images

NUI does not use TrueType fonts or standard image files directly.

Instead, fonts and images must be converted into NUI resources using **NUI Tool**.

## Generate a Font

1. Open **NUI Tool**.
2. Select **Font Converter**.
3. Choose a TrueType font.
4. Select the desired font size.
5. Select the Unicode range if required.
6. Export the generated files.
7. Copy the generated files into your project.

## Generate an Image

1. Open **NUI Tool**.
2. Select **Image Converter**.
3. Choose an image.
4. Select the desired output format.
5. Export the generated files.
6. Copy the generated files into your project.

> **Note**
>
> NUI Tool can generate resources for:
>
> * Memory Font
> * SD Card Font
> * Memory Image
> * SD Card Image

Detailed instructions are available in the **NUI Tool Guide**, **Font Guide**, and **Image Guide**.

# Step 4 – Implement a Display Driver

NUI is hardware-independent.

To communicate with a display, a driver must implement the interface defined by `Nui_Driver_Typedef`.

A display driver typically provides the following operations:

* Draw pixel
* Clear display
* Clear display region
* Draw monochrome bitmap
* Draw color bitmap
* Update display

The complete implementation is described in the **Display Driver Guide**.

---

# Step 5 – Register the Driver

Once the driver has been initialized, register it before using any drawing function.

```c
NUI_REGISTER_Driver(&display_driver);
```

After registration, all NUI drawing functions will automatically use the active display driver.

---

# Step 6 – Draw Your First Text

Include the main library header.

```c
#include "nui.h"
```

Clear the display.

```c
NUI_DISP_CLEAR(ctx, NUI_COLOR_BLACK);
```

Draw a string.

```c
NUI_FONT_DRAW_STRING(ctx,10,10,(uint8_t *)"Hello NUI",&font,NUI_COLOR_WHITE,NUI_COLOR_BLACK);
```

Refresh the display.

```c
NUI_DISP_UPDATE(ctx);
```

---

# Step 7 – Draw Your First Image

Draw an image previously generated by **NUI Tool**.

```c
NUI_IMAGE_DRAW_IMAGE(ctx,20,20&logo);
```

Refresh the display.

```c
NUI_DISP_UPDATE(ctx);
```
