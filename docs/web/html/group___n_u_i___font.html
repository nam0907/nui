Detailed Description

Font rendering module.

This module provides font abstraction, glyph access, UTF-8 text rendering and text drawing utilities.

Fonts can be loaded from memory, SD card or any custom source by implementing the font interface.

typedef struct Nui_Font_Typedef Nui_Font_Typedef

Generic font object.

This structure defines a generic font interface used by NUI.

Different font backends such as memory fonts or SD card fonts can implement this interface and provide glyph data through the callback functions.

Draw a UTF-8 string.

Draws a text string at the specified position using the selected font.

The string is decoded as UTF-8 and rendered character by character using the font backend.
